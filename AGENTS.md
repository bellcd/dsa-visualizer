# dsa-visualizer

Step-by-step visualizations of data structures and algorithms. Each algorithm records a trace as it runs; the renderer plays the trace back.

- Use the terms in `GLOSSARY.md`.
- Read `docs/trace-format.md` before changing `src/trace/` or writing an algorithm: it holds the trace shape, the tracer API and the test contract every algorithm meets.
- Build with the `tdd` skill.
