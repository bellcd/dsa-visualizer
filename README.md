# dsa-visualizer

Step-by-step visualizations of data structures and algorithms.

The words this project uses are in [GLOSSARY.md](GLOSSARY.md); the design is in [docs/trace-format.md](docs/trace-format.md).

## Scripts

- `scripts/largest-files.sh`: prints the 10 largest tracked files under `src/` as `size path` (bytes), largest first. Run it from the repository root; it exits non-zero if `src/` is missing.
