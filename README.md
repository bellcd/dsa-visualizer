# dsa-visualizer

Step-by-step visualizations of data structures and algorithms.

The words this project uses are in [GLOSSARY.md](GLOSSARY.md); the design is in [docs/trace-format.md](docs/trace-format.md).

## Scripts

`scripts/line-counts.sh` prints every tracked file under `src/` with its line count, one `count path` pair per line. It counts every line, blank and comment-only lines included.
